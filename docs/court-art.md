# Court artwork

The 31 square illustrations in `assets/court_art/` were generated for this app. Each file maps to the base Court card with the same `BC` number; for example, `bc08.jpg` is Gatekeepers. All are 500 × 500 JPEGs. Card names, suits, rules text, and agent counts remain live UI text so they stay legible and accessible.

The offline Haunt Roll Fail HTML supplied by the user was inspected for broad visual context: character-led Guild cards and looser, civic Vox scenes. No image from that file or the official card library was copied into these assets. The generated images have no printed rules text or game logos.

Generation used the built-in image-generation tool, one original scene per card. The common Guild prompt requested an edge-to-edge, hand-painted editorial science-fantasy illustration, a central subject legible at thumbnail size, deep navy space with warm gold/copper and cyan accents, and no typography, border, or watermark. The Vox prompt requested a looser poster-painting treatment with copper, parchment, and navy. Each prompt then specified the following card-specific scene:
