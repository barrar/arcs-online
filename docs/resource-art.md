# Resource icon artwork

The five icons in `assets/resource_icons/` are original, generated artwork for the base game's Material, Fuel, Weapon, Relic, and Psionic resources. They use the visual motifs and palettes shown in the [official base rulebook](https://buriedgiant.com/arcs/Arcs_Base_Rulebook.pdf) and the user's offline ARCS reference game, without copying its image files. Each transparent PNG is 128 × 128 pixels.

The icons were generated with Codex's built-in image generation tool. The prompt set requested a small, legible sci-fi game resource icon with transparent background and no text, then specified these distinct motifs:

| Resource | Prompt motif |
| --- | --- |
| Material | A faceted cubic block with purple and warm yellow planes. |
| Fuel | A compact stack of cylindrical fuel cells in olive and gold. |
| Weapon | A retro raygun silhouette in rust orange and warm metal. |
| Relic | A bright four-point celestial star in cyan and blue. |
| Psionic | An abstract mask and eye symbol in teal and magenta. |

The generated images were reduced to 128 × 128 pixels for the game interface.
